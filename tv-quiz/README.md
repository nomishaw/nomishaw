# 📺 答题电视

灵感来自广东一位爸爸的改造：孩子每看 10 分钟电视就要答一道题，答对才能继续看，答错还会追加题目。

这是一个**单文件网页**（`index.html`），不用安装，也不需要服务器。

## 怎么用

1. 在电视浏览器、电视盒子或电脑上打开 `index.html`（电脑可以全屏后投屏到电视）。
2. 选择本地视频（可多选，连续播放），或者粘贴 `.mp4` / YouTube 链接。
3. 按 **P** 键或点右上角「🔒 家长」，输入密码进入家长面板。**首次默认密码 `0000`，请马上修改。**

## 规则（都可以在家长面板里调）

| 设置 | 默认 |
|---|---|
| 每看几分钟答一次题 | 10 分钟（只计真正在播放的时间） |
| 答错后等待 | 58 秒，然后换一道新题 |
| 答错追加题数 | +1 道 |
| 最多累计题数 | 3 道 |
| 每日观看上限 | 不限 |
| 题库 | 初一数学 / 小学高年级数学 / 数学+英语单词 / 自定义 |

自定义题目每行一题：`题目 | 正确答案 | 错误答案1 | 错误答案2 …`

## 家长面板

- **大人解锁 2 小时**：大人看电视时不出题
- **立即锁屏**：画面直接锁住，需家长密码才能打开
- **取消解锁**：恢复答题模式
- **现在就出一道题**
- 今日统计：观看分钟、答对/答错次数，以及每道题的记录（答错时记下孩子选了什么）

## 防作弊小设计

- 刷新页面不会重置计时、欠的题和答错等待
- 答题时用视频自带的播放按钮也播不了
- 家长密码连续输错 3 次锁定 60 秒
- 支持电视遥控器方向键选答案

## 局限

- 数据存在本机浏览器里；不能像新闻里那样用手机远程控制（那需要一个服务器）。
- 只能管住这个网页里的视频，管不住电视自带的其他 App。
